### 私について

日本の田舎で**動物保護区**を運営している台湾人 — 28匹の猫と犬。

**エンジニアではありません。** AIコーディングエージェントを使い、7ヶ月で本番APIプラットフォーム（30以上のAPI、約5万行のコード）を構築しました。学んだこと全てを以下にオープンソースとして公開しています。
